# AGENTS.md

## Cursor Cloud specific instructions

This repository is a **fully static website** (the PROCOPE Afrique showcase/incubator site). It is plain HTML5 + CSS3 (Bootstrap 5) + JavaScript (jQuery, Owl Carousel, WOW.js, etc.). See `README.md` for the page list and file structure.

Key facts for future agents:

- **No build step, no package manager, no tests, no lint.** There is no `package.json`, lockfile, `Makefile`, or CI config. All third-party libraries are vendored (committed) under `lib/`, and CSS under `css/`. Nothing needs to be installed to develop or run the site, so the environment update script is intentionally a no-op.
- **Run it as a static server (development mode).** Serve the repo root over HTTP rather than opening files via `file://` (relative asset paths and the search modal behave best over HTTP). Any static server works; a simple option already available in this environment is `python3 -m http.server 5501` from the repo root. The `.vscode/settings.json` uses VS Code Live Server on port `5501`, so `5501` is the conventional dev port.
- **Entry point:** `index.html` (browser tab title "Accueil - PROCOPE"). Other pages are the top-level `*.html` files (e.g. `candidature.html`, `contact.html`, `service.html`, `actualites.html`).
- **Forms are front-end only.** Contact / homepage compact contact / candidature forms open a prefilled WhatsApp chat via `js/procope.js` — there is no server-side handler. Email public : `procopeafrique@gmail.com` ; téléphone : `+228 96 45 76 95` (Lomé, Togo).
- **Editing content:** text lives directly in the `*.html` files, custom styles in `css/style.css`, and site JS in `js/main.js` + `js/procope.js`. Changes are picked up on browser refresh (no compilation).
- **Dark mode / theming (non-obvious):** the active theme is stored on `<html data-theme="light|dark">`. Each page has a tiny inline `<script>` in `<head>` that applies the saved theme early (from `localStorage` key `procope-theme`, falling back to the OS `prefers-color-scheme`) to avoid a flash. The toggle button is `#theme-toggle` in the navbar; its click handler lives in `js/main.js`. Dark styles are scoped under `html[data-theme="dark"] ...` at the end of `css/style.css` and mostly override Bootstrap utility classes (`.bg-light`, `.bg-white`, `.bg-dark`, `.form-control`, etc.). When adding a new page or section, keep the `<head>` theme-init script and reuse those utility classes so dark mode keeps working automatically.
- **SEO conventions:** per-page `<title>`, meta description/keywords, canonical, Open Graph/Twitter tags and JSON-LD live in each page's `<head>`; `robots.txt` and `sitemap.xml` are at the repo root.
- **Domain-agnostic SEO (important):** the site is built to run on any domain (currently `https://procopeafrique.vercel.app`, later a real `.org` / `.com` / `.tg`) without editing every page. `js/seo.js` runs on each page and rewrites `canonical`, `og:url`, `og:image` and `twitter:image` from the live `window.location.origin`, so those adapt automatically. The static values baked into the HTML (plus `js/seo.js`'s `FALLBACK_ORIGIN`, `robots.txt`, `sitemap.xml` and the JSON-LD absolute URLs) are only a fallback for non-JS crawlers. To switch to a new production domain, run `python3 scripts/set-domain.py https://your-domain` once — it restamps all of those static references in a single command. After a real domain switch, resubmit `sitemap.xml` in Google Search Console.
- **Images:** photos in `img/` are AI-generated and web-optimized (resized + compressed). If you regenerate images, keep them compressed (they were reduced from ~26 MB to <1 MB total) so page speed / SEO is preserved.
- **Homepage interactive features (`js/procope.js`, no backend):** all configurable values live at the top of `js/procope.js`.
  - *TikTok video testimonials* — the `VIDEO_TESTIMONIALS` array holds `{name, role, thumb, url}`; paste the real TikTok video links in `url` (the numeric video id is auto-extracted). The strip is a **step carousel** (advances one card at a time on a timer, not a continuous marquee), pauses on hover / while the modal is open, is drag/swipe-navigable with scroll-snap, shows a one-time swipe tutorial (localStorage key `procope-vt-hint`), and opens each video in a modal (`#videoModal`). Prefer local covers under `img/vt-thumb-*.jpg` (from TikTok oEmbed). Use real handles/short titles in `name`/`role` — never invent person names. Placeholder links (ids like `000...01`) intentionally show the thumbnail + an "Ouvrir sur TikTok" fallback instead of a broken embed; real links play inline. The TikTok brand glyph is an inline SVG because the template's Font Awesome 5.10 has no `fa-tiktok`. Written + video testimonials share one « Témoignages » section on the homepage.
  - *WhatsApp forms* — `#training-form` (candidature « Se former »), `#candidature-form` (dépôt de projet), `#partenaire-form`, and `#contact-form` open a prefilled `wa.me` message. Update `WHATSAPP_NUMBER` (international digits, no `+`). File inputs are UX only — `wa.me` cannot attach files.
  - *Country flags* — the hero mini-flags and the "PROCOPE en Afrique" marquee use `flagcdn.com` images; edit the flag list directly in `index.html`.
  - *Posters / actualités* — affiches `img/affiche-*.jpg` are shown on `actualites.html` (événements passés) via `[data-poster]` + `#posterModal`; the homepage has a compact actualités strip linking there.
  - *Candidature hash deep-links* — `candidature.html#former`, `#projet`, `#emploi`, `#partenaire` (aliases: `#formation`→former, `#incubation`→projet).
- **Disabled pages (hidden pre-launch):** `feature.html`, `price.html`, `quote.html`, `team.html`, `testimonial.html`, `detail.html` and `ressources.html` are kept but inaccessible. They are (1) redirected to `/` by `vercel.json`, (2) redirected client-side by a `PROCOPE:DISABLED-PAGE` block in each page's `<head>`, and (3) commented out in `sitemap.xml`. **`blog.html` redirects to `actualites.html`** (server + client). **To reactivate a disabled page:** remove its `PROCOPE:DISABLED-PAGE` block, delete its `redirects` in `vercel.json`, uncomment its `<url>` in `sitemap.xml`.
- **Navbar (toutes pages actives):** Accueil → À propos de nous → Nos services → Projets incubés → Actualités → Espace candidature → Contact → Plus : Investisseurs & Partenaires (`partenaires.html`).
